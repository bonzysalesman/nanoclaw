# Product Management Skills

You have access to a set of best-practice product management frameworks.
When a user asks you to perform PM workflows (e.g., write a spec, update a roadmap, synthesize research, brainstorm features), you should:

1. Identify the relevant skill in `/app/knowledge-work-plugins/product-management/skills/`
2. Use your file reading tools to read the markdown instructions in that directory.
3. Execute the user's request following those specific guidelines.

## Available Workflows:
- `write-spec`
- `roadmap-update`
- `stakeholder-update`
- `synthesize-research`
- `competitive-brief`
- `metrics-review`
- `product-brainstorming`
- `sprint-planning`
