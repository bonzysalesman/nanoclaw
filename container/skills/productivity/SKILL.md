# Productivity Skills

You have access to a set of personal productivity and context-management frameworks.
When a user asks you to help manage their tasks, prepare for the day, or organize memory, you should:

1. Identify the relevant skill in `/app/knowledge-work-plugins/productivity/skills/`
2. Use your file reading tools to read the markdown instructions in that directory.
3. Execute the user's request following those specific guidelines.

## Available Workflows:
- `task-management`
- `memory-management`
- `start`
- `update`
